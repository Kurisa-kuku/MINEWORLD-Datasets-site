# 常见问题

## 必须使用 Mwarecorder 吗？

不。目录接受回放、原始视频和自定义张量数据集。选择对应格式并说明如何加载即可。Mwarecorder 只是提供视频、状态、动作与事件之间最强的默认对齐。

## 网站会托管我的数据吗？

不会。请把归档上传到稳定的位置并提交链接。GitHub 只托管条目的元数据和封面，数据仍然由你掌控。

## 我的 GitHub 登录信息会存到服务器吗？

不会。网站是静态的。使用浏览器 OAuth 设备流或个人访问令牌时，令牌保存在 `sessionStorage`，只发送给 `api.github.com`。关闭标签页即清除。

## 为什么我不能自己合并提交？

提交和更正会变成 Pull Request，由维护者检查许可证、隐私与链接健康后合并。这是流程要求，不是对你工作的评价。

## 可以匿名提交吗？

请使用申请访问并说明限制。不要冒用他人身份。所有 Issue 和 PR 都是公开的，因此提交的 GitHub 账号可见；请使用你愿意与条目关联的账号。

## 下载是 Google Drive 文件夹，可以吗？

如果无需申请即可公开访问，可以。如果需要权限申请，请选择 **申请访问** 并提供联系方式。不要使用会过期的链接。稳定的对象存储或学术归档 URL 更好。

## “已校验”是什么意思？

对 Mwarecorder 数据而言，指 episode 结构与 tick 对齐通过官方校验器。它不代表内容无偏、法律上无瑕疵或一定有用。请结合质量标注与已知限制一起判断。

## 为什么会出现“暂无翻译”提示？

双语字段允许缺失一种语言，以便条目仍能发布。网站会回退到可用语言并明确提示。如能改进翻译，请提交更正。

## 发布后如何更新数据集？

使用元数据编辑器，或提交更正 Issue。自动化会校验修改并打开 PR。实质性变更请追加历史记录。不要在链接背后静默替换文件，应发布新版本并说明。

## 下载链接失效了怎么办？

使用 **举报问题**，或打开 Issue。定时链接健康工作流也会检查 URL 并标记持续失败。维护者可能会要求替换链接，或把条目改为受限访问。

## 没有再分发许可的数据集可以列出来吗？

只能在规则清楚的情况下：选择 **受限** 或 **申请访问**，说明权利状况，不提供公开下载。如果你根本没有分享权，请不要提交。

## 点赞是怎么计算的？

数据集社区 Issue 上真实的 GitHub 👍 reaction。计数由定时工作流快照。网站不使用隐藏追踪或分析。
